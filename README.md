## Projeto em destaque

### [Agendamento de Exames de Imagem](https://github.com/AndesondaCruz/agendamento-exames)

Aplicação full stack em que o paciente busca um exame, escolhe o médico, vê os horários livres e confirma o agendamento.

- API em NestJS + TypeORM + PostgreSQL, com Redis e rate limiting por IP
- Front-end em React 19 + TypeScript (strict) + TanStack Query + Tailwind CSS
- Testes com Vitest, Supertest, Testing Library e testes de acessibilidade com axe-core
- Docker Compose com Nginx, CI no GitHub Actions e Dependabot
- Desenvolvido com branches por feature, Pull Requests e Conventional Commits

[Aplicação no ar](https://agendamento-exames-eight.vercel.app) · [Documentação da API (Swagger)](https://agendamento-exames-yw6j.onrender.com/api/docs)
